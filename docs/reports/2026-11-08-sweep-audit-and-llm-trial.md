# 扫盘统计修正与赛前大模型试验

## 本次落地

1. 保留原预测、输入与赛果版本；新增只读审计统计。
2. 来源、比赛日与赛事分别筛选。单选命中和多选覆盖各自显示分子与分母；无预测、观望、待赛果、排除单列。
3. 模型和市场对照必须来自同一模型档案的同期概率；官方报价核验距预测最多180秒，不能使用当前报价或数小时前的市场首份记录作同期对照。
4. 使用相同比赛、玩法、让球线和正式赛果计算完整分布的Brier及Log loss；未选方向仍评价分布，取消、身份变更与冲突排除。不同玩法不合并平均，不根据单日少量样本宣布模型优于市场。
5. 扫盘页、CSV及分享图统一统计口径。页面复用TDesign全局蓝白配色、直角和手机换列布局。

## 已核实的局限

2026-11-08本地核查时，当日30场中5场有模型留档、30场有市场参考。5场模型带有同期市场概率，其中3场已有90分钟赛果。数量会随采集与比赛变化，不能把30场市场覆盖称为30场模型覆盖。

旧日志没有完整概率，不计算概率误差；缺少同期市场快照的模型记录仍可单独计数，但不能用于本次同期对照。按赛事筛选与按来源筛选不修改或补写档案。赔率归一化不是AI判断，固定“进取观察”规则也不是AI决策。

## 独立LLM试验：尚未启用

用户同意研究赛前LLM参与，但这不是把现有预测换成LLM的授权。正式训练、选用、结算、档案和本次统计仍按原确定性链路运行。不得把以下设计写成已接入功能。

| 组 | 输入 | 输出与归属 |
| --- | --- | --- |
| 市场基线 | 同时刻官方报价 | 归一化完整概率，独立市场组 |
| 现有模型 | 固定赛事模型及截止前事实 | 冻结现有完整概率 |
| 模型加AI提取特征 | 同一事实包中的新闻、公告，经LLM提取并人工抽查的结构字段 | 新赛事实验候选；必须训练、时间切分与消融评估，不能让LLM任意改现有概率 |
| 独立AI | 同一截止时刻的结构事实及带来源文本 | 研究预测，保存模型版本、提示词、引用、完整概率、拒答、耗时及token用量 |

### 拆分执行与验收

1. **建立前瞻事实包**：首次试验固定开赛前60分钟，记录真实执行时间；没有赶上窗口则缺失，不事后补预测。唯一键为赛事、比赛、协议版本、截止时间；冻结球队身份、规则、赛事模型版本、报价、资料发布时间与首次采集时间。所有证据必须在截止前已取得，响应完成和落盘也必须在开赛前。身份改变取消该次试验，另留原因。
2. **LLM证据提取**：首发、伤停、资格、轮换各字段记录来源ID、引文、发布时间、采集时间和“已确认/预计/未知”。处理网页内指令为不可信数据。没有证据保持未知；禁止从本场赛后xG、赛果或复盘文字生成赛前特征。提取置信度不得当比赛概率。
3. **独立AI前瞻**：只向独立研究任务发送白名单事实包，不含结算或赛后字段，不借用正式预测接口保存AI结果。校验概率有限、范围正确、总和正确及引用存在。失败、超时和拒答同样留档，不能只展示成功场。先限定少量人工启动样本及调用预算，不默认逐分钟付费运行。
4. **结构特征增量模型**：积累有真实时点证据的历史/前瞻样本，再按赛事训练实验候选。训练、验证、测试依时间分开，预先固定参数搜索、留出范围与特征组；比较无文本、仅结构事实、AI提取特征三组，确认是新增信息还是文字包装带来的差异。不跨赛事借用模型。
5. **四组共同样本报告**：按赛事、玩法、固定提前量分层；报告所有纳入、缺失与拒答分母，Brier、Log loss、校准分箱和分箱样本量，以及同场配对误差区间。报告总token、费用、时延和失败率。不得用不同场次的准确率决定优劣，不能挑最好的一次提示词结果。
6. **晋级单独审批**：在预先固定的保留测试和随后前瞻期均证实增益，再决定候选是否供观察。未满足条件保持独立研究；不自动替换已有赛事模型，不回写历史预测。

### 调研依据

- [Football forecasting benchmark, arXiv:2608.04008](https://arxiv.org/abs/2608.04008)：足球前瞻LLM比较；相关预测不能靠投票简单累加为独立证据。
- [Football forecasting study, arXiv:2607.18084](https://arxiv.org/abs/2607.18084)：结果需结合样本交集和预测时点解读，不能据报道准确率承诺本平台增益。
- [Approaching Human-Level Forecasting with Language Models](https://arxiv.org/abs/2402.18563)：检索与结构化预测流程的研究依据，领域结果不直接等同足球验证。

本文件记录试验方案，不提供LLM已提升准确率的结论。
