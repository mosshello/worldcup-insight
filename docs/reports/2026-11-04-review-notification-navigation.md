# 复盘通知无法点击：修复与验收

原因：通知中的“查看复盘”固定指向 `#/reviews`，没有携带比赛编号；用户已经在复盘列表时URL不变，因此没有可见动作。同时复盘组件只在首次加载且尚未选择比赛时读取深链接，不能正确处理同页切换和关闭后重开。

修复：通知使用来源更新记录中的 `match_id` 生成精确链接，并在每次点击时传递打开请求；组件监听目标比赛和请求变化，数据到达后打开对应抽屉，处理完的请求不会因轮询再次打开。比赛间暂存各自未保存笔记，重复打开不覆盖草稿；保存仍走原独立笔记接口。

新增两项浏览器场景：从复盘列表、从比赛中心点击通知；均检查正确比赛、相同URL关闭重开、切换其他比赛再点通知，以及两场未保存笔记分别保留。已有赛果轮询保留笔记、直接比赛链接、保存和导出等用例继续回归。
