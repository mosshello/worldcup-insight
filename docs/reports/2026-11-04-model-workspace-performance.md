# 数据与模型页加载性能

2026-11-04，用户截图显示欧冠工作台长时间加载。实际接口返回成功，但耗时8.553秒、响应约1.56MB，并非前端菜单失效。

## 原因与修复

原工作台先构建全部7个登记赛事再筛选目标赛事，剖析发现一次欧冠读取有40次模型完整性加载、47次数据集读取；来源统计又在逐场计数时反复调用全量比分读取。

- 构建前按所选赛事筛选；仍完整返回轻量赛事选项，未登记赛事发现继续保留。
- 比分资料每次请求计算一次，复用到来源统计与逐场资格；数据库复用上轮已验证的请求级连接。
- 页面只读请求内复用已完整校验的模型快照，以仓库路径、赛事ID、运行ID隔离。作用域退出即释放，不做跨请求或按时间缓存。实际预测归档和模型选用写路径仍执行原完整校验。每个新请求、不同运行、不同赛事重新核验；损坏文件仍拒绝。

没有修改模型参数、训练规则、预测准入、数据库归档或前端API结构。未重新发布前端，本轮修改在本地8891后端生效。

用户原标签的控制接口仍不可用，没有强制刷新或覆盖输入。同一IAB新可见模型页确认加载结束，显示欧冠8场可预测及当前模型，浏览器无错误；截图`models-loaded.jpg`。本轮无前端变更，旧页面后续刷新请求也使用优化后的接口。
