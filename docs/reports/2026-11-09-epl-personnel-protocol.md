# 英超赛前人员信息：单联赛闭环验证协议

在本轮结果计算前固定。本研究不更改生产模型、既有实验或历史预测。

- 范围：仅 `eng.premier`，90分钟五玩法；缺真实体彩整数让球线时不评价让球。目标为2024/25验证、2025/26及2026/27截至运行时已知赛果测试。历史时期曾被其他研究使用，本轮是探索性回放，不能称全新未见测试。
- 输入：每场T−60之前最近、年龄不超过72小时的FPL原始历史快照；按赛季和明确球队名称对应。只使用有原始新闻支持的伤病/存疑/停赛报告，保留来源语义，不能视为完整名单或官方比赛资格。
- 新特征：报告数量、报告球员在同一快照的累计分钟占比、新闻可核验覆盖、分钟不可用标志、快照年龄。季初尚未开踢时分钟可能来自上季，禁止作为当季使用；不将FPL出场概率当成预计分钟。不使用FPL赔率式预测积分、身价或关注热度。
- 原始快照与赛前新闻严格按时点核验；球队及球员身份冲突拒绝。先由确定规则生成数值，再让AI提取并核验来源；AI不得改数值。历史回放不调用今天的LLM猜历史比赛。
- 对照：每月月初重新拟合DC；同一批可用训练样本分别拟合xG/近期比分/休息和追加FPL特征的Poisson。历史赛后xG沿用明确的七天可用假设，赛前FPL使用原始档案时间而非七天假设。
- 参数：Poisson正则化候选仅0.08与0.5；验证期按胜平负Log loss选择。融合仅比较DC权重与增强权重的凸组合，增强权重固定候选0、0.25、0.5、0.75、1。只用验证期选参数，保存决定后执行测试，测试结果不得调参。各玩法使用同一融合权重。
- 训练：只用该折截止前标签可用的历史；每个折保存输入引用、训练ID、标准化参数、模型。测试按真实时间滚动，较早测试赛果只有在后续折截止前可用才进入后续拟合。
- 报告：全目标、基础可预测、人员覆盖、同场共同样本、排除原因；逐玩法单选准确率、多选覆盖、Log loss、Brier、校准。同场市场对照只接纳相同截止之前180秒内的实际胜平负报价，不套收盘赔率。按周聚类bootstrap描述区间，不能靠单次点估计宣布通过。
- 完整性：旧选用指针、模型与原归档不变；新候选按内容摘要追加。最终拟合纳入当前截止前全部合格英超人员样本。用真实未开赛比赛走新模型和AI提取入口，但不写成旧时点预测。
- 通过标准：技术链路通过与效果通过分别报告。覆盖不足、概率误差无改善、区间不能排除无改善时不晋级。完整资格、预计分钟、替补实力、国家队个人负荷、连续亚洲盘及未来200场检验不由本试验冒称完成。
