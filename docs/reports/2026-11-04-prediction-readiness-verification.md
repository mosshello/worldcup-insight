# 每次预测的数据核查与全量验收

日期：2026-11-04，北京时间。接续[来源调研](2026-11-04-data-integration-conclusions.md)。本轮落实的是预测前核查、失败保护和部分通用采集修复，不能将拦截成功解释为所有外部数据已补齐。

## 已实施

- `quality.assess` 返回逐项核查结果、缺失原因和样本数；生产预测入口在计算前、归档前各核查一次。处理期间改期或身份改变拒绝归档。
- 页面只在明确取得 `can_predict: true` 时启用预测；加载失败、缺字段、过期资料均默认禁用。按钮旁直接显示缺失原因，旧预测仍可查看。
- 通过核查的完整测试样本可正常归档，并保存核查规则、源时间和输入；后续缺失不会修改旧版本。模型训练特征、选用和结算逻辑不变。
- 500来源比赛ID、双方球队ID与业务比赛身份一起保存；再次采集可跳过滚动索引，但仍验证详情球队和开球时间。改期、换赛事、换队不沿用旧映射。
- ESPN主客历史按同赛事、指定主客、非中立、常规完场、时间截止和唯一事件提取；不足5场明确阻止，不混其他赛事凑数。
- 部分来源失败保留原字段及原时间，并标陈旧；明确成功的空响应覆盖旧内容，避免永远保留已撤回的名单。新的官方消息不会被失败来源的旧消息整体覆盖。

## 核查规则

| 项目 | 要求 |
|---|---|
| 身份与阶段 | 精确比赛、赛事、双方及开球时间一致，未开赛、未取消/暂停/延期 |
| 赔率 | 保留原有完整在售玩法与180秒内核验规则 |
| 基本面 | 来源时间不晚于当前时点或开球，30分钟内有效；不能用聚合时间冒充源时间 |
| 近期与主客 | 双方各5场去重、有效比分和时间明确的样本；主客方向正确 |
| 交锋 | 明确已查，允许核查后无记录；未查不能当无交锋 |
| 阵容 | 双方各11个唯一球员、无已知人员冲突；提前一小时以上允许预计阵容 |
| 临场 | 一小时内必须双方正式首发，名单与人员核验时间不超过5分钟 |
| 伤停与资格 | 明确覆盖双方、本赛事、本场，保存来源链接及核验时间；少量新闻或空名单不能视为完整 |

这些阈值是操作层完整性门槛，不是已验证的模型精度提升。当前接入没有能够出具完整双方人员核验的提供方，因此仍会阻止新预测。不得通过手填 `complete=true` 恢复可预测状态。

本场赛后xG、统计和事件不作为赛前必填，未启用的跨赛事模型特征也不列为必填。外部赔率、后续赛程等辅助资料仍单独报告缺口；核查通过不等于所有辅助提供方字段均有数据。
