# 足球分析产品：真实数据与可扩展架构

## 目标

产品覆盖持续更新的官方竞彩足球场次，支持跨日期、跨赛事、未来比赛与历史复盘。“今天能生成预测”是实际验收场景，不是产品的数据边界。界面遵循 TDesign，删除演示数据入口和运行时静态比赛内容。

## 同类产品参考

- [Sofascore](https://www.sofascore.com/)：日期、赛事、关注和比赛状态为独立维度；比赛详情包含球队表现、阵容、统计与赔率变化。
- [FotMob](https://www.fotmob.com/)：球队/赛事关注、赛程与比赛详情形成长期入口。

上述页面用于产品结构参考。数据供应与展示分离，不将其他产品页面视为已获得授权的数据接口。

## 分层

### 用户故事与业务流程

| 使用者的任务 | 页面与结果 |
| --- | --- |
| 找到可以研究的比赛 | 比赛中心按销售日、赛事、状态、玩法和关注筛选；保留开赛时间 |
| 了解两队情况 | 基本面查看近期实际赛果、主客表现、排名、休息时间；阵容页区别确认与缺失 |
| 判断价格变化 | 赔率页展示五种玩法、各玩法单关状态、来源更新时间和历史变化 |
| 形成赛前判断 | 生成基线预测；可请求 AI 解读；查看依据、风险并记录自己的笔记 |
| 比较前后判断 | 预测版本保存输入快照；切换旧版不会重新计算或覆盖原结论 |
| 验证预测表现 | 官方赛果到齐后对照最后一版赛前方向，写复盘；取消比赛不计命中 |
| 维护长期产品 | 数据与模型页展示实际覆盖、来源状态和模型版本；缺失能力明确标注 |

业务顺序：官方场次同步 → 跨来源比赛匹配 → 赔率和基本面采集 → 快照持久化 → 用户生成预测 / AI 解读 → 赛前版本归档 → 官方赛果核实 → 复盘。历史样本积累后才能进入训练与样本外评估，当前不伪装训练服务已上线。

当前同步由页面轮询或主动操作触发；无人访问时不会自动采集。后续后台调度复用同一应用服务，不能将浏览器轮询当作生产调度系统。

### 技术边界

1. **数据适配器**：体彩官方场次/五种玩法/历史 SP；ESPN 近期赛果、正式首发、场地。后续增加授权伤停、xG、外盘适配器。
2. **统一领域数据**：比赛 ID 使用 `provider:id`，分别保留赛事 ID、球队 ID、销售日、开赛时间、市场代码、单关状态、来源更新时间和采集时间。
3. **应用服务**：来源校验、缓存时效、并发去重、比赛状态、预测与复盘。接口以 `/api/v1` 版本化。
4. **存储**：SQLite 保存比赛、赔率快照、详情缓存、不可覆盖的分析输入与输出、关注、笔记。当前 workspace 为 local，未来账号隔离需服务端鉴权后扩展 workspace，而非相信客户端传入用户 ID。
5. **预测引擎**：注册计算版本，输入快照可追溯；AI 解释独立于概率计算。
6. **前端**：只消费真实接口。无数据、未确认、过期、接口错误为独立状态，不自动填入示例。

## 当前真实能力

- 持续读取官方场次，五种玩法分别判断单关；源状态失效后不继续标记在售。
- 日期与赛事筛选对所有已采集记录生效，历史从实际采集开始积累。
- 体育统计按赛事、双方球队缩写（明确别名表）、开赛时间联合匹配；歧义或不匹配时不关联。
- 正式首发只有来源提供完整 11 名首发时显示确认；不会用上一场首发冒充本场首发。
- 市场基线对完整胜平负做去水；未开售普通胜平负时，仅在半全场九项完整时推导全场分布。
- 双方均有至少 3 场赛前赛果时，使用固定收缩的近期进失球 Poisson 估计，与市场按 20%/80% 混合。此为可解释、尚未样本外校准的基线，不宣称训练完成或预测准确率。
- 比分与总进球分别使用完整相应市场的分布，不对展示的少数比分重新归一化。
- AI 解读只在用户点击时调用既有 DeepSeek 配置，不改写模型概率。
- 开赛后禁止创建新的赛前版本；赛果与复盘作为独立记录。
- 复盘以体彩官方结算结果为准，不用可能包含加时的其他赛果直接结算 90 分钟预测。

## 后续扩展契约

赛事映射集中在 `sources.LEAGUES`；球队别名按赛事限定，不按单场写条件。新来源必须返回统一 DTO 与来源时间。模型新增版本不能修改历史版本。训练必须使用按时间切分的样本，先与市场基线比较，再进行影子验证，不能凭单场命中激活。

伤停、xG、外盘、账号权限、定时任务部署和训练服务尚未达到完整生产运营条件。应分别接入和验证，不在界面放置虚构任务、指标或成功状态。

## 验收

- 当日实际场次核对官方 ID、球队、日期、SP、单关状态。
- 至少一场完成实时赔率读取、基本面匹配、预测、数据库归档、刷新恢复。
- 修改系统日期与换赛事无硬编码今日限制。
- 来源失败不回退演示数据，不将缓存当实时，不将未来赛果放入特征。
- 历史版本不可覆盖；相同输入幂等；跨来源错误匹配拒绝；已开赛预测拒绝。
