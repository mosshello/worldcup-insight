# 五大联赛数据与细化训练方案

日期：2026-11-05。用户优先级：英超、西甲、德甲、意甲、法甲；先补数据，再确定模型。本文是研究协议，不是训练完成或效果认证。爆冷监控另立项目，不代替普通比赛预测。

## 本轮交付边界

2026-11-05后续更新：已将9,358场基础样本分别导入五个赛事数据集，并关联8,580场第三方Understat存档xG；尚未训练或选用新模型。以下采集边界保留第一阶段记录，最新覆盖、来源限制及脚本见[补采与入库验收](reports/2026-11-05-big-five-supplement-and-import.md)。新增赛后资料不自动成为已训练特征。

- 五个赛事分别采集 2021/22—2025/26 和 2026/27 已完场历史，保留原始响应、实际下载时间、SHA256、失败及隔离原因。
- ESPN 为结果、半场、历史首发、球员及比赛统计来源；FotMob 为独立赛果对照及逐场 xG/射门资料来源。每项事实保留来源，不混算供应商指标。
- 历史首发是在本次赛后补采的事实，不是当年赛前发布快照。历史赔率、历史伤停和当时名单发布时间不能凭现有页面补造。
- 采集输出位于 `data/research/big-five/2026-11-05/`，未导入现有训练注册表、未训练、未选用、未改历史预测。来源商业使用依据仍未核实。
- 采集器：`scripts/collect_big_five.py`、`scripts/collect_big_five_xg.py`。原始响应压缩保存；可用缓存只在摘要一致时复用。赛季覆盖审计以球队数及完整主客双循环对阵表为依据，不只检查总场数。

## 先验收数据

每个联赛、每个赛季出独立验收表：期望场次、实际场次、球队数、重复对阵、缺失对阵、半场、双方首发、关键统计、xG、双源一致数、冲突数。2026/27 进行中，不能把未踢比赛算作漏采。

| 数据层 | 收集和验收 | 训练使用方式 |
|---|---|---|
| 比赛身份 | 来源赛事 ID、赛季、主客来源球队 ID、开球 UTC、90 分钟口径；不根据队名猜赛事 | 本赛事固定身份，未知映射隔离 |
| 全场/半场 | 赛程与详情一致；半场两段之和等于全场；加时、点球、判罚胜负单独处理 | 本场标签，不作为本场赛前特征 |
| 射门/射正/角球/控球/红牌 | 对应同侧球队，字段逐项覆盖；零值与缺失区分 | 仅此前已可用比赛的滚动统计；红牌影响另做敏感性分析 |
| xG/xGA | 精确匹配比赛；原始来源与版本独立保存；不把自建预期进球称为供应商 xG | 先验收连续性，再计算此前比赛的 xG 趋势；缺失机制需消融 |
| 首发与球员 | 每侧 11 个不同首发 ID；球员逐场统计、替补与换人保留 | 可研究此前阵容连续性；禁止用赛后补采的目标比赛首发模拟赛前已知 |
| 休息/赛程 | 本赛事历史开球时间可直接验证；跨赛事日程另建显式政策 | 本赛事间隔不能冒充真实休息天数；未验证跨赛事日程不进主模型 |
| 伤停/资格 | 需要可追溯历史发布时间及该赛事适用性 | 本轮没有完整历史快照，不进入回测、不填“无人伤停” |
| 赔率/盘口 | 需报价时间、盘口种类、让球数、供应商及开球前适用性 | 市场参考独立；没有对应历史线不能宣称让球盘口验证完成 |

结果可用时间沿用显式“赛后七天或采集时间”的历史假设时，需同时做 1/3/7 天延迟敏感性实验，报告是假设回测。真实前瞻从新采集事实的实际首次观测时间开始。数据修正追加版本，旧版本不重写。

双源对照只能按明确映射、相同主客与时间完成。名称完全一致可作为人工审查映射依据，差异名需显式别名表；不做模糊匹配自动放行。不同来源比分或开球时间冲突保留双方原文，不能挑对模型有利的版本。

## 模型调研结论

### 别人实际公开了什么

| 来源 | 可核查的公开方法 | 对本项目的含义 |
|---|---|---|
| [Opta 赛季预测](https://theanalyst.com/articles/opta-football-predictions) | 用市场赔率与 Opta 实力排名估计单场胜平负，再对余下赛程做大量模拟 | 模拟次数不是训练数据量；不能把含市场输入的结果宣传成纯足球模型 |
| [Opta 实力排名方法，2026-07](https://theanalyst.com/articles/power-rankings-your-club-ranked) | 分层 Elo，结合实际赛果和可用的 xG；公开说明其赛果/xG 更新权重经预测效果优化 | 可借鉴动态实力与 xG 增强思想；其跨联赛层级政策不能直接搬进本项目的单赛事训练 |
| [StatsBomb xG 方法说明](https://blogarchive.statsbomb.com/articles/soccer/upgrading-expected-goals/) | 梯度提升树、细粒度射门情境、特征关系约束与平滑 | 这是射门转化概率模型，不是直接输出赛前比分的聊天大模型；需要我们尚未完整拥有的逐次射门数据 |

上述公开说明支持使用专门统计模型和机器学习模型。它们没有提供可直接复刻的完整生产训练代码，也没有证实“每个联赛必须使用不同算法”。本项目继续遵守 LLM 仅用于赛后证据解释的约束。

### 本项目候选

不能根据“英超激烈、意甲防守”等印象预先宣布五个冠军算法。五个联赛先共享候选方法清单，各自独立训练、选参、校准、测试；最后胜出的模型可能不同，也可能相同。

| 任务 | 基线 | 核心候选 | 主要选择指标 |
|---|---|---|---|
| 胜平负 | 本赛事历史频率、Elo 逻辑回归、现有攻防泊松 | 动态双变量进球模型的边际概率；CatBoost/LightGBM 三分类；验证后融合 | Log loss 主指标，Brier/分项校准约束 |
| 全场比分 | 固定 1–1 仅作命中对照；本赛事经验分布、独立泊松 | 联合 Dixon–Coles；动态双变量泊松；残差支持时再试更灵活计数分布 | 完整比分分布 Log score；0–0/1–1/4+ 概率校准、Top1/Top3 覆盖 |
| 总进球 | 固定 2/3 选项对照；历史总进球分布 | 上述比分分布边际；直接总进球计数/有序分布模型 | 0—6/7+ Log loss、RPS；两项选择命中与覆盖，不只比较均值误差 |
| 净胜球/让球 | 进球分布推导的净胜球 | 动态 Skellam 或直接净胜球有序模型 | 净胜球分布误差；仅有真实历史盘口时评让球结算 |
| 半场/全场 | 既有条件二项分配 | 半场、下半场联合计数模型 | 联合概率 Log loss，不能用全场赛后事件预测半场 |

净胜球模型不能单独推出总进球或精确比分。不同玩法模型独立展示版本与概率来源；只有经过一致性约束和验证的联合产物，才能宣称同一套相互一致的概率。不能把胜平负分类概率硬塞进旧比分表。

### 五个联赛分别需要核查的重点

| 联赛 | 独立研究重点 | 候选实验 |
|---|---|---|
| 英超 | xG 与实际进球差、主客作用、队伍跨赛季变化、阵容连续性 | xG 增强动态攻防/DC 与增强树分类分别比较 |
| 西甲 | 平局概率、低比分格子校准、不同强度组的误差 | 联合 DC 与动态双变量模型对照；树分类不自动加平局权重 |
| 德甲 | 高总进球尾部、净胜球、模型是否低估大比分 | 动态计数模型；有条件过度离散时试负二项/混合分布 |
| 意甲 | 半场与全场相关、主客、赛季漂移、低比分修正是否有增益 | 联合 DC、半场/下半场模型与增强分类器 |
| 法甲 | 2023/24 从 20 队变 18 队、规则时期、升班马和小样本收缩 | 本赛事动态贝叶斯/正则化模型；按赛制时期分组验证 |

以上是待检验的实验重点，不是已证实的联赛规律。过度离散应看拟合后的条件残差，不能仅由整个联赛进球方差大于均值决定模型。也不能通过人为扩大尾部来增加“看起来大胆”的比分。

## 训练细节

### 1. 冻结数据与评估时间

- 每个联赛单独固定数据摘要、映射版本、字段覆盖、来源、可用时间政策、代码版本、依赖和随机种子。
- 开发区间：2021/22—2023/24。采用按实际开球时间的扩展窗口，至少一个完整赛季起步，按半赛季验证；同时开球的比赛必须同组。每次拟合只读当时已可用结果。
- 选择区间：2024/25 前半季（2024-07-01 至 2025-01-01）。根据预先固定的主指标与共同可评估样本选择候选。
- 概率校准区间：2024/25 后半季（2025-01-01 至 2025-07-01）。单独拟合校准器；不得回流训练后再冒充未见样本。
- 保留测试：2025/26 整季。基础数据完整性检查不等于模型选优；一旦读取模型在此区间的表现，就登记为已使用，不能反复调到满意后再称独立测试。
- 2026/27 已发生部分仅作后续历史稳定性检查。真正独立前瞻从协议和模型冻结后的未开赛比赛开始，至少覆盖约 300 场/联赛及足够时间；不足时继续观察，不能借别的联赛补数。
- 预测时点先固定 T-24h；T-60min 是另一套试验，只有首发在该截止前实际已发布且已观测才可使用。不把 T-60min 后才公布的名单倒填。

### 2. 特征逐层增加，逐层做消融

F0：本赛事球队攻防、主客、时间衰减、样本量。

F1：双方近 5/10/20 场进失球、射门/射正及对应失球方指标；指数加权与同主客拆分；对手强弱修正。窗口不足保留真实样本量，收缩先验仅从训练折估计。

F2：此前比赛 xG/xGA、非点球 xG（来源确有时）、射门质量、实际进球减 xG 的趋势；不把偶然超额进球直接当稳定能力。每种供应商单独实验。

F3：过去首发连续性、球员出场贡献和阵容变动。目标首发仅在有历史赛前发布时间的独立队列试验；没有历史伤停就不造“伤停影响分”。

F4：赔率只进入单独的市场增强实验，保留纯足球模型和市场基线，不在业务上混淆。

每层报告对上一层的增益、样本覆盖变化、缺失模式和分组误差。插补、缩放、类别编码和特征筛选都仅在训练折拟合；不能把全赛季积分、赛后排名或未来滚动平均作为赛前输入。

### 3. 有限、有记录的调参

- 时间半衰期候选 90/180/365 天，窗口候选最近 2/3/全部可用赛季，联合比较而非凭感觉改数。
- 攻防模型记录目标函数、约束、正则化、收敛状态；不收敛失败，不能静默输出旧参数。
- 树模型先限浅树（深度 3—5、叶子 7—31、较大最小叶样本），强正则化，每模型族/联赛最多 24 组预先登记配置。早停集取训练尾段，不消耗最终测试或校准区间。
- CatBoost 的时间顺序和类别统计需明确配置；随机种子 3 个只用于稳定性，不挑最幸运种子。
- 只在样本外预测上学习融合权重，权重非负且总和为一，另留融合验证时间段。没有共同覆盖不比较不同样本上的分数。
- 复杂计数模型、大型神经网络不作为第一轮默认候选；先证明简单增强模型的增益和数据规模适用性。

### 4. 验收与拒绝标准

- 必报完整概率的 Log loss/Brier/RPS、校准图、Top1/Top3、总进球 Top2、概率质量/尾部质量和选择集中率。不能只报命中或只报胜平负。
- 分主客、球队、升班马、样本量、赛季、前后半季、进球档、预测强弱差评估；样本不足的组明确标注，不能用偶然的单队表现选模。
- 固定 1–1、固定 2/3 是明确的展示策略对照；另有只用训练历史估计的经验概率基线。固定选择命中与概率分布误差分开解释。
- 对共同样本做按比赛周分块 bootstrap，报告相对基线的差值及置信区间，考虑重复球队/时间依赖，不用独立单场假设夸大显著性。
- 主指标无稳定改善、校准明显恶化、某关键组严重退化、身份/时间泄漏或来源断档时拒绝升级。不能为增加比分种类牺牲真实概率表现。
- 训练生成候选；选用另行操作。历史预测、原输入、原模型摘要和结算版本不可修改。

## 公开依据及适用限度

1. [Dixon–Coles 原论文](https://rss.onlinelibrary.wiley.com/doi/10.1111/1467-9876.00065)：低比分相关及动态球队实力的经典基线；不是现代五大联赛最佳模型证明。
2. [Koopman & Lit，动态比赛预测](https://research.vu.nl/en/publications/forecasting-football-match-results-in-national-league-competition-2/)：比较双变量进球、净胜球与赛果目标，支持把目标和动态参数分开研究；历史论文成绩不能迁移成本项目成绩。
3. [Mead 等，xG 与未来表现](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0282295)：支持研究比单纯比分更细的表现特征，不表示任意供应商 xG 均有同等增益。
4. [LightGBM 参数文档](https://lightgbm.readthedocs.io/en/latest/Parameters.html)：计数和分类目标不同；当前只有预期进球回归不等于已验证完整比分分布。
5. [CatBoost 时间顺序参数](https://catboost.ai/docs/en/references/training-parameters/common)：`has_time` 控制相关步骤的随机排列；仍需自行保证全部特征、早停与数据切分无未来信息。
6. [概率校准文档](https://scikit-learn.org/stable/modules/calibration.html)：校准器需使用与模型拟合分离的数据；本项目采用时间隔离，不能直接套随机交叉验证。
7. [LFP 18 队调整公告](https://www.lfp.fr/article/l-assemblee-generale-adopte-a-97-28-le-passage-a-18-clubs)：法甲赛季完整性期望从 2023/24 起改变。
8. [Football-Data 数据说明](https://football-data.co.uk/data.php)：当前自动化训练产品使用限制，以及 2025-07-23 后 Pinnacle 历史报价时效问题。仅作来源调研，本轮不批量入训。

完整实时采集结果与未完成项在同日数据验收报告中记录，不能用此计划代替实际完成证据。
