比赛筛选

Forebet

官方功能页列出日期筛选、胜平负概率、比分、大小球、近期战绩、主客场表现、积分榜和关注比赛。

借鉴：列表直接显示三项概率；点击比赛再展开依据，减少首屏信息负担。

官方称预测由统计算法生成。本次未获得可复现的完整算法及独立效果验证，不将宣传命中率作为模型选型依据。已查看浏览器中的实际比赛列表，并对照官方功能说明。

比赛事实

Sofascore

官方页面介绍按赛事浏览赛程和比分，提供球队近期比赛、积分榜、比赛统计、赔率变化，以及球队与比赛关注。

借鉴：单场分析使用清晰分区；球队表现和数据来源作为判断依据，与预测结论分开。

它首先是比分与统计产品，不能把球迷投票或球员评分当成经过校准的胜率。已查看实际赛程首页；本次未完整体验其动态单场详情页。

赛事推演

Opta Analyst

官方说明把市场赔率和 Opta Power Rankings 用于单场胜平负，再反复模拟剩余赛程，得到各队最终排名概率。

借鉴：单场预测与赛季预测独立组织。先完成比赛页，再考虑冠军、前四或晋级概率。

方法概览公开，完整生产参数和训练数据未在本次资料中开放。不能仅凭“超级计算机”名称认定比市场更准确。

可复用模型

penaltyblog

开源 Python 工具提供 Poisson、Dixon–Coles 等进球模型、时间权重、中立场处理和统一比分概率输出，并提供回测示例。

借鉴：让胜平负、比分和总进球来自同一套概率分布；用统一接口比较模型。

已阅读模型文档及 Dixon–Coles 类源码，未安装运行或重做回测。文档与主分支 API 命名存在差异，集成前需要锁定版本。

评估框架

Dixon–Coles 市场基准项目

Charliedrakebro 的项目公开描述时间衰减、逐周向前回测与市场对比。作者报告其简单模型在所测样本上没有战胜市场。

借鉴：保留每次赛前预测，比较模型与同时间点市场概率；不要用单一命中率代替完整评估。

本次核对仓库说明，未复现其指标或独立审计数据。这是评估方法参考，不是已验证的效果保证。

这次调研怎样落到第一版

  1. 找比赛：赛事筛选、演示日期、球队搜索、关注比赛。
  2. 看判断：主胜 / 平局 / 客胜三个概率并列，标明赔率来源；比分不冒充确定结果。
  3. 看依据：赔率对照、主客场信息、球队状态与数据覆盖。
  4. 看边界：未接入的俱乐部模型、伤停和历史表现显示缺失状态。

后续接入真实数据后，再做独立模型与市场概率对比。赛季冠军和欧冠晋级模拟放到后续版本。

核查范围：官方产品说明、公开模型文档、部分源码。未登录付费产品、未复现第三方回测；页面方案为本项目的设计判断。
